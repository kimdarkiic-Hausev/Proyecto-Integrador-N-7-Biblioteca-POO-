**📝 Descripción del Proyecto**
Este sistema fue desarrollado para modelar y gestionar las operaciones principales de una biblioteca universitaria. La aplicación permite administrar socios (estudiantes y docentes), registrar el catálogo de libros, gestionar los préstamos vigentes y emitir informes sobre el estado de la biblioteca.

El desarrollo se organizó de manera colaborativa aplicando los principios de la Programación Orientada a Objetos (POO), haciendo uso de **BlueJ** como entorno de desarrollo, **Git/GitHub** para el control de versiones y **Trello** para la gestión del flujo de trabajo.
